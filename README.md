# Visible Utilities

**Bring the wires back.**

American-style utility poles, power lines, telecom cables and building drops for the districts you choose in Cities: Skylines II.

[Get the mod on Paradox Mods](https://mods.paradoxplaza.com/mods/158830/Windows) · [Report a bug](https://github.com/llkj11/VisibleUtilities/issues/new?template=bug_report.yml) · [Suggest an improvement](https://github.com/llkj11/VisibleUtilities/issues/new?template=feature_request.yml)

## Known issues

- Some buildings remain unwired; unusual road and building assets can produce awkward placement.
- Shared wiring between townhomes is experimental.
- Bridges, quays, highways and elevated or underground roads are unsupported.
- Underground utilities are planned.

## Getting started

Enable Visible Utilities in your playset and restart the game. Select a district and turn on **Visible Utilities**. Poles appear first, followed by building connections. The district panel shows progress.

Start with one district. Larger areas can take tens of seconds to finish and may stutter while generating.

## Feedback and bug reports

This repository is the public issue tracker and player guide. Use **Issues** to report a problem or suggest an improvement. Screenshots and reproduction steps help distinguish routing problems from conflicts with particular assets or mods.

Before opening a report, search existing issues. For a placement problem, include both a close-up and a wider view showing the street and nearby buildings. For performance problems, include city population, district size, hardware and whether the slowdown continues after generation finishes.

Logs are optional but useful. On Windows, the game stores them under `%USERPROFILE%\AppData\LocalLow\Colossal Order\Cities Skylines II`. Attach the relevant mod log from `Logs` and, for crashes, `Player.log`. Check logs for personal information before posting them publicly.

The mod is visual only. It does not change electricity, internet service or city budgets.

Current release: **0.1.0-beta.2**, tested on Windows with **Cities: Skylines II 1.6.0f1**.
